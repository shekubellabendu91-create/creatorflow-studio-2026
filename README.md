# CreatorFlow

CreatorFlow is a lightweight, browser-based content studio that turns a topic into a short-form content pack:

- Hook
- Script
- Caption
- Call to action
- Hashtags

## Features

- No account required
- No API key required
- Works on phones and computers
- Uses plain HTML, CSS and JavaScript
- No user content is sent to a server
- Copy buttons for every generated section

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a new GitHub repository named `creatorflow`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch** and select the `main` branch.
5. Save and wait for GitHub Pages to publish the site.
