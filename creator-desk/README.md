# CreatorDesk

CreatorDesk is a lightweight, browser-only client and project tracker for independent creators and small freelance teams.

## Features

- Add projects with a client, project name, USD budget, due date, status, and notes.
- Search by client, project, or notes and filter by status.
- Edit project status and delete individual projects.
- See total project count, active projects, and the combined budget.
- Export saved projects as a CSV file.
- Responsive layout for desktop and mobile screens.

## Run locally

Open `index.html` in a modern browser. No build process, account, server, API key, or third-party package is required.

## Data and privacy

Projects are stored in the browser's local storage on the device. There is no cloud sync or account recovery. Export a CSV backup before clearing browser data. Avoid entering sensitive client details.

## Current limitations

This is a static prototype. It does not send invoices, process payments, sync between devices, or provide authentication or multi-user collaboration.
