# Changelog

Notable changes to CreatorFlow Studio are documented here. Earlier releases did not have a maintained changelog, so unverifiable historical details are intentionally omitted.

## [1.1.3] - 2026-10-23
- Added regression tests for content generation and CreatorDesk.
- Added CI coverage across Node.js 18, 20, and 22, coverage reporting, production dependency auditing, and Docker image validation.
- Documented architecture, deployment, security, and contribution workflows.

## [Unreleased]
- Added shared CreatorDesk project validation and boundary tests.
- Added ESLint checks to improve maintainability.
- Added optional AWS S3 and CloudFront infrastructure as code with a private origin.
